# PIDcontrollerDesign
### PID Controller Design, Tuning and Performance Analysis

This project investigates PID controller design and tuning for industrial control systems, using MATLAB and Simulink to analyse closed-loop behaviour and evaluate controller performance. Several tuning approaches are implemented, including the Ziegler–Nichols open-loop and closed-loop methods, alongside manual tuning based on critical gain and oscillation characteristics. First-order plus dead-time approximations are also examined to derive controller parameters and assess their effectiveness in representing the original system dynamics.


The resulting P, PI and PID controllers are evaluated through time- and frequency-domain analysis, with particular attention to rise time, settling time, overshoot, steady-state error and stability. Their responses are compared across different system models and tuning configurations, highlighting the trade-offs between transient performance, steady-state accuracy and stability. The project also examines practical implementation considerations, including control-signal sensitivity and actuator saturation.
